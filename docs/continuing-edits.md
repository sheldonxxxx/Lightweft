# Continue an edit with less context

Keep the active conversation focused on the photograph, the current decision, and the evidence needed to judge it. Store complete operations, editor state, and earlier renders in your ignored workspace.

## Keep a per-photo checkpoint

At a meaningful saved milestone, update a short note beside the photo's review artifacts. Reuse an existing session or review note instead of creating a second record. Include:

- Source identity and hash; editor session and revision; accepted reference or version; mask IDs; current geometry; saved-state and export paths.
- Intended result, accepted qualities, and subject or scene content that must be preserved.
- Unresolved defects; inspected overview and detail regions; corresponding render paths and view parameters; next justified action.

A few hundred words will usually suffice. This note is a continuation aid, not an editable recipe or a substitute for the saved editor state. For a collection, keep separate per-photo notes and carry only the shared style brief and the current photo into each decision.

After a context reset, reconcile the note with the live editor revision and the reference the user reviewed. Reopen the relevant rendered evidence before judging detail. Temporary variants may share a session revision while showing different pixels: retain their patches, reference versions, crop regions, and rendering options too.

## Read and review selectively

Load the core editing guidance, the applicable genre, and the execution reference needed for the next operation. Reuse known schemas until the editor's schema identity changes. Read bounded branches of saved responses and logs when diagnosing an issue.

Review an overview after a meaningful group of edits. Inspect changed local corrections at matched native detail and check their relationship to the whole image. Use multi-view diagnostics to resolve a specific uncertainty. Keep the accepted reference and inspect the actual exported file before delivery.

Publish candidates through the [shared review app](../review/README.md). Inspect rendered files directly for photographic decisions; operate the browser when interaction, feedback, alignment, or display behavior needs checking. Showing an existing comparison does not itself require another interface audit.

For RapidRAW response formats, selected schema reads, and connection recovery, follow the companion's [MCP guide](https://github.com/sheldonxxxx/RapidRAW/blob/main/mcp/README.md). This workflow does not prescribe a smaller preview size, fewer necessary detail checks, a particular model, or additional agents.
